## Overview

Ragents is a pure Ruby, Ractor-based AI agent framework for concurrent, isolated agent execution. It uses RubyLLM for access to 500+ models across all major providers.

## Features

### Core Components

| Component | Description |
|-----------|-------------|
| `Message` | Immutable, Ractor-shareable messages |
| `Context` | Immutable conversation state with truncation/forking |
| `Tool` | Declarative tool DSL with JSON Schema support |
| `Agent` | Base class with system prompts, tools, Ractor execution |
| `Provider` | RubyLLM integration (500+ models) |
| `Orchestrator` | Multi-agent coordination |

### Key Capabilities

- **Ractor-First Concurrency**: Agents run in isolated Ractors for true parallelism
- **Pure Ruby**: No Rails dependencies (optional Rails integration via Railtie)
- **Message-Passing Architecture**: Immutable messages and contexts for safe concurrency
- **Tool-Based Actions**: Declarative tool definitions with JSON Schema
- **500+ Models**: OpenAI, Anthropic, Gemini, Ollama via RubyLLM
- **Multi-Agent Orchestration**: Sequential workflows, parallel execution, supervision

## Installation

```ruby
gem "ragents"
```

Requires Ruby 4.0+.

## Quick Example

```ruby
class ResearchAgent < Ragents::Agent
  system_prompt "You are a research assistant."

  tool :search_web do
    description "Search the web"
    parameter :query, type: :string, required: true
    execute { |query:| SearchService.search(query) }
  end
end

provider = Ragents::Providers::RubyLLM.new(model: "gpt-4o")
agent = ResearchAgent.new(provider: provider)
result = agent.run(input: "Research Ruby 4.0 Ractor improvements")
```
